# 且记 · 使用说明

文字版说明。详细版本在应用内“帮助 → 使用说明”。

## 安装

打开 `且记-Mac-0.2.4-构建26-Apple芯片.dmg`，将「且记」拖到旁边的「Applications（应用程序）」入口。复制完成后推出磁盘映像，从「应用程序」启动。

当前版本未经 Apple 公证，首次打开可能需要在系统设置中确认。升级已有版本前，请先阅读[升级与卸载](#升级与卸载)。

## 打开与两个形态

且记常驻菜单栏。点菜单栏图标，再选“显示 / 收起”或“侧边任务单”打开清单；“完整窗口”用于集中整理。两种形态共用同一份任务和编辑状态，完整窗口可以移动和缩放。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `⌘1` / `⌘2` | 切换完整窗口 / 侧边清单 |
| `⌘K` | 聚焦新任务输入框 |
| `⌘P` | 打印任务纸或保存 PDF |
| `⌥↑` / `⌥↓` | 任务文字获得焦点后，调整顺序或移入相邻分组 |

## 三条使用规则

**今天、最近、长远由手动安排。** 选择“新增到”的分组决定新任务放在哪里；设置提醒不会移动任务，第二天也不会自动换组或归档。

**重复提醒持续提醒同一条未完成任务。** 它从最近一次匹配的时刻开始，点“完成”后停止，不会自动生成下一周期的任务。

**删除可以恢复。** 删除和“清理已完成”都先移入回收站；永久删除需要单独确认。

## 提醒

提醒支持一次性、每天、工作日和每周四种设置：先选择时间或频率，再点“设置提醒”保存。没有确认的选择不会生效，关闭或 Esc 保留原有提醒。

没有出现横幅时，先到通知中心确认是“未送达”，还是被专注模式或通知权限挡住了。

已知问题：系统通知中选择“15 分钟后再提醒”后，系统记录的动作与实际不符，差异尚未定位，这段路径不保证可用。需要延后时，请回到应用内修改提醒时间，并核对保存后的显示。

## 数据在哪

任务与回收记录保存在 `~/Library/Application Support/且记/` 的 JSON 工作区，应用运行时不依赖网络，也不需要账号，没有云端或跨设备同步。

退出时会提交当前文字编辑并确认保存；保存失败会取消退出并提示。未确认的提醒草稿不会自动生效。

## 导入、导出与备份

“文件”菜单可导出任务、合并导入 JSON 和查看导入前备份。导入时同 ID 保留当前版本，不覆盖现有记录；导出不包含尚未添加的新建草稿；单个导入文件不超过 20,000 条 / 20 MB。

## 打印

A4 纵向输出，保留标题、日期、分组、未完成任务正文、文字格式和勾选框，隐藏输入区、已完成任务、行内动作和提醒信息。打印简化不改变应用内的提醒设置。

## 升级与卸载

升级前先用“文件 → 导出任务…”另存 JSON，再正常退出且记。替换应用后核对“关于且记”的版本、任务和回收记录。

本版应用标识改为 `com.luyaowo.qieji`，任务和回收记录继续使用原数据目录，通知权限需要重新授权；窗口形态、展开状态和位置等偏好可能恢复默认。

如果从旧标识版本升级，替换应用前先关闭旧版的“开机启动”，并确认旧版已完全退出。升级后检查新版本的通知权限和“开机启动”，只运行一个副本，避免两份应用同时写入同一任务目录。旧版已排通知是否残留或重复尚未验证，升级后也需核对。

不再使用时，把“且记”拖入废纸篓即可，任务数据仍在 `~/Library/Application Support/且记/`，需要时可手动清理。

## 边界

适用于 Apple 芯片 Mac、macOS 14 或更新版本。当前版本为本地 ad-hoc 签名，尚未完成 Developer ID 签名和 Apple 公证。通知送达、实体打印和完整无障碍仍在验证。
