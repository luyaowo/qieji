且记 Windows

一张可以随手记录、慢慢整理的任务纸。

记录和整理

选择今天、最近或长远，写下任务并添加。点击文字编辑，选中文字可以加粗或添加底色。拖动可以排序或跨组移动。分组由你手动安排。

保存与退出

工具栏显示“已保存”后，任务和回收记录已写入本机。遇到“保存失败”，请保留窗口，重试保存或先导出任务。切换纸边、隐藏和退出前都会提交当前编辑；保存失败时取消操作。

纸边、窗口与托盘

点击“收起到侧边”留下屏幕右侧的小纸边，点击纸边展开清单，上下拖动调整位置。“完整窗口”恢复普通窗口。切换时使用同一份清单，不重新加载页面。

点击窗口右上角关闭按钮会隐藏到托盘。左键点击托盘图标打开完整清单，右键菜单可打开清单、显示纸边或退出。托盘可能藏在时钟旁的向上箭头里；托盘创建失败时，关闭按钮改为保存后退出。

“退出且记”或工具栏“退出”会彻底退出程序。中文输入尚未确认时，请先完成输入再切换或退出。Mac 上运行此工程时，托盘入口显示在顶部菜单栏，属于本机预览。

导入、导出与回收站

导出包含任务和回收记录，不含尚未添加的新任务草稿。导入先预览数量，再备份当前工作区并合并；同 ID 保留当前版本。单次导入不超过 20,000 条或 20 MB。

删除和清理已完成先移入回收站，可以恢复。永久删除需要再次确认。

快捷键

Ctrl+K 聚焦新任务输入，Ctrl+S 重试保存，Ctrl+B 加粗选中文字，Alt+方向键调整获得焦点的任务顺序。

当前版本

当前提供完整窗口、纸边收展和托盘入口。系统提醒和打印尚未开放。导入文件中的原有提醒设置会保留。

任务保存在本机，不需要账号，不自动跨设备同步。开发版与正式版使用独立数据目录。
