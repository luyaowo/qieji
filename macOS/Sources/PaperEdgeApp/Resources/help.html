且记 · 使用说明

一张放在 Mac 桌边的任务纸。随手记下，持续看见，需要时提醒，也能打印带走。

适用于 Apple 芯片 Mac，macOS 14 或更新版本。任务保存在本机，Mac 与 iPhone 目前不互通。

开始记录设置提醒恢复任务保存与迁移安装与升级

开始记录

  1. 在底部输入一件要做的事，用“新增到：”选择今天、最近或长远，再按回车或点击加号添加。
  2. 单击任务文字可以编辑，按回车保存；按 Esc 取消这次文字编辑。鼠标点击其他位置也会提交文字编辑。
  3. 点任务左侧的方框标记完成，再点一次可以恢复未完成。

分组由你安排，不随日期自动移动。到了第二天，任务不会自动换组或消失；“最近”不是系统计算的未来七天。可以拖动任务调整顺序、跨组移动。

首次打开会提供 5 条示例任务。可以保留体验，也可以清除未修改的示例；你新增的任务和修改过的示例会保留。

“侧边”适合随手查看，“完整窗口”适合集中安排，两种形态共用同一份清单。关闭完整窗口会回到侧边入口；完全退出应用请使用“且记 → 退出且记”。

设置提醒

鼠标移到未完成任务上，或用键盘把焦点移到任务，点击右侧铃铛打开提醒设置。已经设置提醒的任务，也可以直接点击文字下方的提醒时间。

  1. 选择快捷时间，或选择提醒频率并填写时间。每周提醒还需选择星期。
  2. 查看“待保存”的下次提醒时间，再点击“设置提醒”生效。快捷时间也需要这一步确认。
  3. “取消修改”、Esc 或关闭尚未提交的提醒表单，会保留原有提醒。“取消提醒”则会撤掉已有提醒。

重复提醒持续提醒同一条待办，完成任务后停止。每天、工作日和每周都从最近一次匹配的时间开始，不会每天自动创建新任务。设置提醒不会移动任务的分组。

系统通知可以打开对应任务、标记“完成”，或选择“15 分钟后再提醒”。对于重复提醒，延后只影响本次，原有重复时刻与星期保留。完成、删除或取消提醒会撤回对应待发通知。

已知问题：系统通知中选择“15 分钟后再提醒”后，系统记录的动作与实际不符，差异尚未定位，这段路径不保证可用。需要延后时，请回到应用内修改提醒时间，并核对保存后的显示。

错过的一次性提醒会在清单顶部汇总为“已错过”，可在那里完成或延后。重复提醒不进入错过汇总。提醒数量较多时，应用按任务整组排入最近 60 条通知，打开应用或修改任务时会重新排期。

没有看到通知时

  • 先打开 Mac 的通知中心，查找“且记提醒”。通知进入通知中心与屏幕弹出横幅是两件事。
  • 在“系统设置 → 通知 → 且记”中检查通知权限和展示方式。应用内出现“通知未开启”图标时，可点击前往系统设置。
  • 专注模式（比如工作模式）可能延迟通知或影响横幅展示。不同应用可以有不同的允许规则，请检查当前模式。
  • 实际送达和展示受系统状态影响。“15 分钟后再提醒”的已知异常见上方说明；需要延后时，回到应用内修改提醒时间。

恢复任务

任务右侧的“删”会把它移入回收站。工具栏扫帚“清理已完成”会收纳所有分组中的已完成任务，同样可以从回收站恢复；操作后也有短暂的“撤销”入口。

点击工具栏垃圾桶打开回收站，可逐条恢复。“永久删除”和“清空已删除”会要求确认，确认后无法通过回收站恢复。点击“返回任务”回到清单。

保存、备份与迁移

任务和回收记录保存在本机。应用退出时会提交当前文字编辑并保存；如果写入失败，退出会取消并提示。未确认的提醒表单不会随退出自动应用。

“文件”菜单提供“导出任务…”“导入任务…”和“在 Finder 中显示备份”。导出包含任务、文字格式、提醒规则及回收记录，不含尚未添加的输入草稿。

换电脑时，先在原电脑导出 JSON 文件，再到新电脑导入。导入是合并，不是整份覆盖：同 ID 保留当前版本，新记录追加。导入前会备份当前工作区，备份失败会取消导入。单个导入文件上限为 20 MB、20,000 条任务及回收记录。

“在 Finder 中显示备份”打开导入前备份的目录；它不是云同步，也不代表已经有异地备份。你可以把导出的 JSON 另存到自己选择的位置。

打印与键盘

工具栏打印按钮或 ⌘P 可打印未完成任务，也可在系统打印窗口保存 PDF。打印保留标题、日期、分组、任务正文、文字格式和勾选框，隐藏操作按钮、输入框、回收站、已完成任务，以及提醒时间、重复频率、下次提醒和通知状态图标。应用内提醒设置不受影响。

应用内可用 ⌘1 切换完整窗口、⌘2 切换侧边、⌘K 聚焦输入。任务文字获得焦点后，用 ⌥↑ / ⌥↓ 调整顺序，到组边界可进入相邻分组。选中文字后可加粗或设置底色，格式工具支持 Tab 和回车操作。

安装与升级

ZIP 解压后，将且记应用放入“应用程序”。升级前先导出任务并保留旧应用，再正常退出旧版，替换应用后重新打开，核对“关于且记”的版本和任务内容。

本版应用标识改为 com.luyaowo.qieji，任务和回收记录继续使用原数据目录，通知权限需要重新授权；窗口形态、展开状态和位置等偏好可能恢复默认。

从旧标识版本升级时，替换应用前先关闭旧版“开机启动”并确认已完全退出。升级后检查新版本的通知权限和“开机启动”，只运行一个副本，避免同时写入同一任务目录。旧版已排通知是否残留或重复尚未验证，升级后也需核对。

只复制应用不会把任务一起带走；任务迁移请使用导出和导入。回退应用版本时，也应先保留当前任务。导入旧备份仍按合并规则处理，不会覆盖同 ID 的当前任务，也不会把整份清单自动回到过去的状态。
